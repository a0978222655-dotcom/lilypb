# Lily Prep｜皮拉提斯備課室

延伸自 [pilates.prep 初版](https://a0978222655-dotcom.github.io/pilates.prep/)，為手機和平板設計的繁體中文備課工具。沿用日曆、動作庫、地點與練習計時功能，重新設計備課流程與視覺。

## 開始開發

需要 Node.js 20 以上，沒有第三方 JavaScript 套件或外部 CDN 依賴。

```sh
cd /workspace/lilypb
npm ci
npm run dev
```

開發伺服器預設使用 4173 埠。可選用 `PORT` 環境變數更換埠號。本機備課不需要 API 金鑰或資料庫。跨裝置共用可選用 Supabase，請看[雲端啟用步驟](docs/cloud-setup.md)。

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

`build` 檢查 JavaScript 語法並產生 `dist/` 靜態網站，支援部署到 GitHub Pages 的子路徑。建置不會發布網站。雲端任務可直接使用既有 checkout，不需要另建 Git worktree。

## 可以使用的功能

- **備課總覽**：月曆、備課狀態、本月課程與時間統計。同一天可安排多堂課，並依上課時間排序。
- **課程編排**：課程名稱、地點與器材備註、時段、目標時間、教學筆記；可新增／刪除階段，調整動作順序、組數、每組分鐘與口令。即時計算階段與總時間，並可複製課程。
- **動作資料庫**：保留初版六個動作；支援搜尋、分類、新增與編輯。修改動作庫不會改寫已備好的課程。
- **課程範本**：30、45、60 分鐘的可編輯起點。實際時間與標示一致。
- **學生管理**：姓名／稱呼、學習目標、教學提醒，可關聯多人至課程並查看關聯課程與練習進度。這是備課及練習紀錄，並非簽到、收費或出席紀錄。
- **上課模式**：勾選完成動作，使用可暫停／繼續的倒數計時；切換背景後按實際經過時間校正。瀏覽器被系統完全關閉時，計時器不會繼續執行。
- **資料與設定**：地點管理、JSON 匯出／匯入與損壞資料救援。匯入會驗證格式並要求確認。
- **雲端帳號與同步**：Supabase Email 註冊／登入、帳號分離、跨裝置讀取與自動儲存、斷線編輯暫存、版本衝突提示與取代前備份。須先建立專案、執行資料表設定並部署新版網站才能正式啟用。
- **iPhone／iPad App**：可由 Safari 加入主畫面，以獨立視窗開啟；提供 App 圖示、安裝說明、離線程式快取與手動確認更新。詳見 [iPhone／iPad 安裝說明](docs/iphone-ipad.md)。

## 資料保存與初版相容

未登入時，資料保存在目前瀏覽器的 `localStorage`，本機鍵名為 `lilypb_v2`。登入已設定的 Supabase 後，帳號資料使用獨立本機快取，並同步至該使用者的雲端工作區。同一帳號可在不同裝置共用；本機資料不會自動上傳，首次登入可明確選擇搬入。更換網址／裝置、清除網站資料或使用無痕模式，可能無法保留尚未同步的資料，請定期匯出備份。備份包含學生紀錄，請妥善保存。

若新版與初版使用相同網站來源（協定、網域及埠），首次開啟時會讀取初版 `pilates_prep_v1`，保留動作、分組、地點、課表、組數、備註及練習完成狀態。新版**不會改寫或刪除初版儲存資料**。不同來源不能直接讀取初版資料；可在「資料與設定」匯入初版 JSON 格式備份。新版備份因支援多堂課及學生資料，不保證可被初版讀取。

建置版提供 Service Worker：首次連網並成功準備離線快取後，可離線重新開啟程式與使用已保存的本機／帳號資料。離線無法首次登入、下載尚未取得的雲端資料或同步；恢復連線後會重試。系統清除瀏覽資料或快取後，仍需重新連網準備。開發用 `npm run dev` 不啟用新的離線快取，避免修改程式時顯示舊版。即時程序不會隨雲端環境快照保留，進入新任務後須重新執行開發伺服器。

## 測試

`npm test` 使用 Node.js 內建測試工具，驗證舊資料遷移、課程時間、課表複製、同日多堂課、時段排序、學生關聯、動作快照與排序、無效備份、損壞資料處理，以及模擬 Supabase API 的帳號隔離、同步、斷線、版本衝突、憑證更新與資料保留。

若環境已提供 Python Playwright 與 Chromium，可在開發伺服器執行中測試真實瀏覽器操作：

```sh
python3 tests/browser_smoke.py
python3 tests/browser_cloud.py
```

可用 `LILYPB_TEST_URL` 和 `CHROMIUM_PATH` 指定測試網址與 Chromium 路徑。測試使用獨立瀏覽器 context，不會寫入你的日常備課資料；截圖存於 `/tmp/lilypb-checks/`。檢查手機 390px、平板 820px／1024px、桌面 1440px 的學生管理、動作搜尋、備課、複製、上課計時、資料持久化、備份匯入／匯出與橫向溢出。

雲端瀏覽器測試攔截 Supabase HTTP 請求，模擬兩台裝置的登入、資料搬入、共用與衝突處理；不會建立真實 Supabase 專案或驗證正式 RLS。正式啟用前仍須完成[雲端啟用步驟](docs/cloud-setup.md)的實際雙裝置與雙帳號驗證。

離線與 App 更新必須測試建置版。先執行 `npm run build`、以 `PORT=4174 node scripts/serve.mjs --dist` 啟動另一個伺服器，再執行 `python3 tests/browser_pwa.py`。可用 `LILYPB_PWA_TEST_URL` 更改測試入口。測試涵蓋安裝圖示、離線重新載入／新視窗、離線編輯、API 不被快取、GitHub Pages 子路徑、不同安裝路徑的快取隔離、確認更新與更新失敗時保留可用舊版。這些為 Chromium 瀏覽器測試；iPhone／iPad Safari 的安裝與主畫面行為仍需正式部署後實機確認。
