# 在 iPhone／iPad 使用 Lily Prep

這是可加入主畫面的網頁 App（PWA）。正式 HTTPS 網站部署完成後，就能在 iPhone 與 iPad 安裝；目前不需要上架 App Store，也不是可直接安裝的 IPA 檔案。

## 安裝到主畫面

1. 用 **Safari** 開啟已部署的新版 Lily Prep 網址。聊天中的原始碼或截圖連結不能用來安裝。
2. 先確認原本的備課已完成雲端同步，或匯出一份 JSON 備份。
3. 開啟 Safari 的「分享」選單（方框向上箭頭圖示；有些版本在更多選單裡）。
4. 選「加入主畫面」；若看不到，向下捲動分享選單尋找。
5. 名稱可保留為 **Lily Prep**。若出現「以網頁 App 打開」選項，請保持開啟，再按「加入」。
6. 點主畫面的 Lily Prep 圖示開啟。若已啟用 Supabase，使用與電腦相同的帳號登入，即可取用雲端資料。

你也可以從 App 的「資料與設定」→「加入主畫面與 App 更新」，查看操作說明與離線準備狀態。Safari 與主畫面 App 可能使用不同的儲存空間，不要假設 Safari 的本機資料一定會自動出現在 App 裡；可使用雲端同步或 JSON 備份轉移。

## 離線與更新

- 首次連網開啟建置版後，程式會準備離線檔案；在安裝說明確認顯示「已準備好離線開啟」後，可離線重新開啟備課室。
- 程式快取只包含靜態 HTML、CSS、JavaScript、圖示與公開設定。登入／雲端 API 回應與學生資料不會放進 Service Worker 快取；備課資料仍由本機儲存及帳號同步處理。
- 離線時可讀取、編輯已存在的資料；未下載過的雲端資料、首次登入與同步都需要網路。請等到「已同步到雲端」，再切換另一台裝置。
- 瀏覽器或系統清除網站資料／快取後，需要重新連網準備；尚未同步的資料仍應備份。
- 新版不會在備課中自動重新整理。出現「有新版本可更新」時，先儲存表單，再選擇「更新並重新開啟」。目前計時會結束，本機已儲存資料會保留。
- 若新版離線檔案下載失敗，會繼續保留可用的舊版；恢復連線後可再檢查版本。
- 計時器可校正切換背景後的經過時間，但 App 被 iOS 完全關閉時不會繼續執行，也沒有背景通知或鬧鐘功能。

## 部署與開發

```sh
npm ci
npm test
npm run build
```

將 `dist/` **全部檔案**部署到同一個 HTTPS 網站，包含 `sw.js`、`manifest.webmanifest`、`assets/` 和 `src/`。可部署到 GitHub Pages 的子路徑，不要只上傳 `index.html`。後續更新需重新建置／部署，App 下載完整新版後會提示更新。

`npm run dev` 的原始碼開發模式不註冊新的離線快取；正式建置版才啟用。若同一網址之前測試過建置版，舊 Service Worker 仍可能控制該網址，開發時請改用另一個埠或獨立瀏覽器 context，避免清除真實使用者的資料。

Supabase 專案、帳號隔離與跨裝置同步需另外完成 [雲端設定](cloud-setup.md)。發布 Codex 開發環境不等於部署網站。

目前已提供 iOS 所需的圖示、Manifest、主畫面中繼資料、觸控欄位與安全區版面；自動驗證使用 Chromium 的手機／平板尺寸，未使用真實 iPhone／iPad 或 Safari 引擎。部署後請在你的裝置確認加入主畫面、重新登入、旋轉畫面、離線開啟及更新流程。
